# 图书馆管理系统（Library Management System）

基于 **Flask + MySQL** 的图书馆管理系统，覆盖读者服务、馆藏管理、座位资源调度、积分激励四类业务场景，实现从注册登录到荣誉榜单的完整业务闭环。

## 功能特性

### 账号与权限
- 读者自助注册登录；管理员账号由系统初始化自动创建
- 服务端强制鉴权（装饰器实现）：图书增删改仅管理员可操作，借阅归还仅读者可执行
- 未登录访问受保护页面自动跳转登录，越权访问返回 403

### 图书管理
- 管理员录入 / 编辑 / 删除图书，字段含书名、作者、出版社、数量、余量、馆藏位置
- 读者可按书名 / 作者 / 出版社搜索浏览
- 借阅采用 `UPDATE ... WHERE remaining > 0` 原子扣减，防止并发超借；归还自动回补余量

### 座位预约
- 3 个自习区共 30 个座位，实时显示空闲 / 占用 / 我的三种状态
- 预约后锁定 **1 小时**签到窗口，须到场签到
- 预约超时未签到自动标记违约并**封禁 24 小时**（请求钩子扫描过期记录实现，等价定时任务但零额外依赖）
- 支持主动取消预约、签退释放座位

### 扫码签到（到场验证）
- 每个座位分配随机暗码，可生成并打印二维码贴至座位
- 签到接口校验「扫描的座位暗码 == 预约的座位」，杜绝远程签到刷积分
- 伪造其他座位暗码会被拒绝，且预约状态不被篡改

### 积分与荣誉
- 按时签到获得积分，积分按月独立结算，每月冠军授予「每月自习之星」
- 年度按累计积分排名，年末授予「年度自习之星」
- 积分榜含周榜、月榜、年榜、逐月积分明细矩阵与历史荣誉档案

## 数据库设计（7 张表）

| 表 | 说明 |
| --- | --- |
| `users` | 用户（读者/管理员双角色、积分、封禁截止时间） |
| `books` | 图书（含 CHECK 约束保证余量在 0~总数之间） |
| `borrows` | 借阅记录（借出 / 归还两态） |
| `seats` | 座位（含随机暗码，用于扫码签到） |
| `seat_reservations` | 预约记录（预约/已签到/已离开/违约/已取消五态） |
| `points_log` | 积分流水（周/月/年榜统计依据） |
| `honors` | 荣誉称号（UNIQUE 约束防重复授予） |

## 快速开始

### 1. 环境准备
```bash
# 创建虚拟环境并安装依赖
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

### 2. 初始化数据库
```sql
-- 在 MySQL 中创建数据库
CREATE DATABASE library DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```
```bash
# 执行建表脚本（7 张表 + 30 个座位 + 管理员账号）
python db.py
```

如需修改数据库连接信息，编辑 `db.py` 顶部的连接常量（或改用环境变量）。

### 3. 启动应用
```bash
python app.py
```
浏览器访问 http://127.0.0.1:5000

## 测试说明

开发过程中设计并执行了 30+ 项功能测试用例，覆盖三个维度：

1. **角色权限矩阵**：读者 / 管理员 / 未登录 × 图书管理、借阅、越权 URL 访问等操作组合，验证服务端鉴权有效（读者伪造管理员表单提交被拦截且不产生脏数据）
2. **业务边界与并发**：库存为 0 时借阅被拒、余量越界校验、预约超时违约封禁、重复预约拦截
3. **异常与伪造**：使用其他座位的暗码伪造签到被拒绝、无效暗码返回 404、过期预约不可签到

端到端回归脚本（`practice_e2e.py`）覆盖「注册 → 预约 → 扫码签到 → 积分入账 → 荣誉上榜」全链路，单轮验证耗时 < 1 分钟。
